
# Phishing Email Detection and Investigation System

## Project Overview

A Python-based cybersecurity project designed to
detect and investigate potentially malicious emails.

The application aims to analyze email headers,
sender information, URLs, attachments and Indicators
of Compromise (IOCs).

## Project Objectives

- Analyze suspicious email headers.
- Identify potential email spoofing.
- Detect suspicious URLs and domains.
- Analyze email attachments.
- Extract Indicators of Compromise.
- Integrate threat intelligence services.
- Calculate phishing risk scores.
- Generate investigation reports.

## Technology Stack

- Python
- Flask
- HTML, CSS, Bootstrap
- SQLite
- VirusTotal API
- URLhaus
- YARA

## Project Structure

- modules/ - Security analysis modules
- templates/ - HTML templates
- static/ - CSS and JavaScript
